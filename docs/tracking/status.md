## 남은 작업의 순서

1. 입력 변수·기간·월간 달력·정보 시점·실자료 출처를 고정하고 Step1/2가 같은 PCA·군집 결과를 공유하도록 수정한다. 미래 입력 교란·동일 창 분할·날짜 누락/중복 검사를 다시 수행한다.
2. LOOCV 절편 항, 초기 낙폭, 활성 결측 수익, fallback 유효 표본 수, 시각화 파일 계약과 누락 파일 복구를 수정한다. 기대 산식 자체를 바꾸지 않고 반례가 해소되는지 검증한다.
3. Naive/BL/MVO, lns/los/mx, GMM/NBER·조건부 전이 분석, 무작위 레짐 대조·검정, 10% 변동성 조정 그림을 구현한다. BL 및 통계·지표 정책은 저자 자료나 명시적인 가정으로 정한다.
4. 같은 WRDS 자료와 당시 거시경제 빈티지를 확보하여 동일 기간의 성과표·통계적 유의성을 재현한다. 거래비용·공개 지연·체결 시각을 반영한 평가는 별도 설정으로 비교한다.

추가 비공개 자료가 존재하는지는 확인되지 않았다. 자료가 도착하면 기존 결과의 영향을 재검토한다. 현재 로컬 진단 실행을 막는 오류는 없고, 전체 실증 재현은 자료 확보가 선행 조건이다.

# 공유 상태 기반 재구현과 실용적 마무리

## 배경

독립 Step별 PCA·군집은 동일 레짐 번호의 의미를 달라지게 만들었다. 사용자는 실제 ETF로 결함을 수정하고 quant 연구에 맞게 구조를 정리하도록 요청했다.

## 선택과 대안

역할별 패키지와 공통 WindowState를 채택했다. 기존 파일 전달 구조를 부분 보수하면 반복 계산과 분할 불일치 경계가 남으므로 활성 실행 경로를 CLI로 이관했다. 원 코드는 Git 버전과 보존 목록으로 유지한다.

실제 제공 가능한 Yahoo·FRED를 쓰며 48개월을 유지해 시작을 2003-02로 정했다. 상장 전 가격 합성이나 학습 기간 축소로 논문 시작연도에 맞추지 않는다. 고정 개정자료와 과거 공개본 지연 가정을 별도 실행한다.

전체 기본 결과와 충분한 작은 검증이 확보된 뒤 사용자가 과검증을 줄여 마무리하도록 요청했다. 이에 장기간 대조군·민감도 반복을 추가하지 않고 실행 범위·코드 버전을 보고서에 명시한다. 이 선택은 빠른 인계를 가능하게 하지만 최종 코드로 논문 전체 실험을 인증하는 주장은 할 수 없게 한다.

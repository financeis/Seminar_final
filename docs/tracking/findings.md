# 남아 있는 연구 한계

원 코드의 결함·누락 대응은 새 패키지와 보고서에서 구분해 기록한다. 처리 목록은 reports/reproduction/report/finding_resolution.json에 기록한다. 구 감사 파일은 현재 체크아웃에서 제거했다.

| 조건과 한계 | 영향 | 이번에 남기는 이유와 후속 접근 |
|---|---|---|
| Yahoo 수정주가와 현재 ETF 목록 사용 | 논문 WRDS 가격·종목 이력과 수익이 달라질 수 있다. | 동일 WRDS 자료가 제공되지 않았다. 추후 정식 입력 adapter로 비교한다. |
| FRED 월별 공개본에 지연 가정 적용 | 정확한 일별 최초 발표 시각·모든 수정 이력을 보장하지 못한다. | 공식 월별 아카이브의 시간 해상도 한계다. 일별 발표 기록 확보 시 가용 시각 계약을 강화한다. |
| 원문 BL·지표·전이·소표본 정책 일부 미정 | 수치 차이가 곧 구현 오류라는 결론은 불가능하다. | 명시한 연구 가정으로 구현했고 민감도 연결까지 확인했다. 저자 설정이나 추가 자료가 필요하다. |
| 전체 대조군·민감도 반복 미실행 | 전략 우위·유의성·정책 안정성의 장기 결론을 낼 수 없다. | 과검증을 줄이라는 사용자 지시로 생략했다. 저장된 suite 설정으로 후속 실행할 수 있다. |
| 원 NPZ의 과거 생성 계보 부재 | 옛 저장물의 정확한 입력·모형을 사후 확정할 수 없다. | 존재하지 않던 정보를 만들지 않는다. 새 실행부터 전체 계보를 기록한다. |

전체 표본의 R0를 경기침체의 정답이나 48개월 rolling 전략의 성과로 해석하지 않는다. 2020년 달 제외 결과는 표본 선택에 따른 군집 변화의 진단이다.

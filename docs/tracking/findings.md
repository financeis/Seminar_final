# 해결하지 않은 연구 문제

현재 진단은 원 구현을 보존하고 오류·누락·모호함과 수정안을 제공하는 범위다. 아래 소스 변경은 후속 작업이며, 실제 자료가 필요한 확인도 별도로 남아 있다. 전체 근거와 정확한 코드 위치는 reports/paper_audit/audit_report.md 및 findings.json에 보존했다.

| 재현 조건과 문제 | 영향 | 현재 해결하지 않은 이유 | 접근 방향 |
|---|---|---|---|
| 같은 FRED 48행을 Step1/2에 주어도 최적 번호 정렬 후 10행의 분류가 다르다. 서로 다른 PCA 좌표의 직접 매칭도 불변성을 깨뜨린다. | 확률과 조건부 예측의 의미, 창 사이 레짐 해석이 달라진다. | 공유 결과물 도입은 연구 소스 수정 범위다. | 입력·PCA·분할을 한 번 생성하고 두 단계의 소속·식별자를 검사한다. |
| 미래 RPI 결측만 변경하면 과거 확률이 달라지고, 2020년 4·5월 삭제 후 48행이 50개월에 걸친다. | 과거 정보 집합과 월별 평가기간이 달라진다. | 변수 선별·결측·월간 달력 정책의 변경이 필요하다. | 과거 정보로 선별하고 달력을 유지하며 교란·연속성 검사를 다시 수행한다. |
| 절편 포함 Ridge의 analytic LOO 점수가 직접 재학습과 다르고, 최초 −10% 손실의 MaxDD가 0이다. | λ 선택과 예측, 손실 평가가 바뀔 수 있다. | 독립 반례는 확인했지만 소스 수정은 선택한 진단 범위 밖이다. | 절편 hat diagonal 보정과 초기 자산 포함 계산을 적용한 뒤 같은 기대값으로 비교한다. |
| 날짜 누락·중복과 활성 NaN 수익이 조용히 통과하고, 원 Step5 출력을 시각화가 읽지 못한다. 일부 선행 파일만 있을 때 복구도 실패한다. | 표본·성과가 달라지거나 분석이 중단된다. | 생산자·소비자 코드의 계약 수정이 필요하다. | 날짜 유일성·수익 유한성·파일/열 계약을 검사하고 모든 파일 존재 조합을 검증한다. |
| 합성 ETF가 실제 loader와 같은 이름으로 저장되며 기존 NPZ에는 생성 입력·모형 계보가 부족하다. | 과거 결과의 출처와 동일 구현 여부를 확정할 수 없다. | 과거 실행의 누락 메타데이터를 사후에 만들어낼 수 없다. | 다음 실행부터 출처·seed·입력 해시·생성 버전·레짐 식별자를 보존한다. |
| Naive/BL/MVO, 다른 배분 전략, 대조·통계 검정과 일부 그림이 없다. | 논문 전체 비교 결과를 만들 수 없다. | 새 모델과 전략 개발은 후속 범위다. | 공통 입력·레짐·평가 문제를 먼저 해결하고 각 수식의 작은 독립 검증을 추가한다. |
| 실제 ETF/WRDS, 공개일·실시간 빈티지·체결 시각이 없고 원문 일부 설정도 미정이다. | 전체 성과와 실시간 이용 가능성을 검증하지 못한다. | 외부 자료 또는 연구 가정의 확정이 필요하다. | 원 자료를 확보하고 가정별 결과를 명시한다. 합성 반례로 실증 성과를 대신하지 않는다. |

경계 입력의 군집 실패·비유한 전처리·확률 끝점·소표본 fallback·지표 관례도 원인별 보고서에 남아 있다. 이들은 실제 전 기간의 발생 빈도와 영향이 아직 측정되지 않았다. 자료나 후속 구현이 바뀌면 기존 확인 범위를 유지하면서 해결 여부를 갱신한다.

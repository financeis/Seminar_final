# 구현에서 확인한 주의점

## 코로나 시기 제외

원 README는 4월 제외를 설명했지만 실제 완전 관측행 전처리는 4·5월을 지웠다. 4월 CP3Mx·COMPAPFFx 결측과 차분의 전파가 원인이다. 사용자 설명에 따라 3·4월 제외도 별도로 비교했고, 전체 표본 R0는 1개에서 304개로 늘었다. 4·5월 제외에서는 293개였다. 이는 전체 표본을 다시 적합한 사후 진단이며 rolling 48개월 전략의 성과가 아니다. 원자료와 기본 백테스트 달력은 그대로 유지했다.

## 번호·좌표·절편

서로 다른 PCA 창의 같은 열은 같은 경제 축이 아니다. 확률과 조건부 예측은 동일 WindowState를 공유하게 수정했다. 창 사이 해석에는 공통 좌표 복원이 필요하다.

Ridge 계수가 맞더라도 LOO 점수는 틀릴 수 있다. 절편을 포함한 hat diagonal에는 1/n이 들어간다. 고정 λ 적합의 유효성과 LOO 오차의 유효성도 분리했다. forward 검증에서는 내부 LOO가 불필요하므로 고정 적합 후보 API를 사용한다.

## 실행과 환경

Windows에서 scipy.stats의 모듈 최상위 import가 import 부작용 검사와 충돌했다. 통계 함수 내부의 지연 import로 해결했고 통계 산식은 바꾸지 않았다. 한글 로그는 명시적인 Python 실행 파일과 -X utf8로 남긴다.

같은 출력 폴더의 재사용은 충돌 오류다. 재실행은 새 폴더로 수행한다. 오래된 결과에는 당시 revision을 유지한다. 전체 기간 기본 결과는 1541930, 후속 대조·민감도 짧은 실행은 ac069ce에서 생성됐다. 후속 수정 후 앞선 전체 결과를 최신 버전 인증으로 바꾸지 않는다.

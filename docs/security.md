# 로컬 실행과 자료 보호

로그인·계좌·주문·공개 서버가 없는 로컬 연구 도구다. 운영체제의 읽기·쓰기 권한을 사용하며 별도 자격 증명 수명이나 회전 기능은 없다.

| 실행 주체 | 허용 동작 | 제한과 실패 처리 |
|---|---|---|
| data acquire | Yahoo·공식 FRED 자료 요청, 새 스냅샷 기록 | 필수 자료 실패 시 합성 대체 없이 실패한다. 기존 해시가 다르면 덮어쓰지 않는다. |
| run·suite | 고정 원자료 읽기, 전용 결과 폴더 쓰기 | 실행 중 입력·코드 변경을 같은 출처의 성공으로 기록하지 않는다. |
| report·verify | 결과와 참조 읽기, 별도 보고서·검사 결과 생성 | 손상된 해시·누락 참조·불일치를 성공으로 표시하지 않는다. |
| 역사 감사 | 지정 Git 버전에서 임시 폴더의 원 코드 실행 | 소켓 차단은 부작용 제한이며 악성 코드의 보안 격리를 보장하지 않는다. |

기록 대상은 요청·취득 시각·제공자·자료 해시·코드·설정·seed·패키지 버전·결과·예외다. 쿠키·사용자 도구 설정·비밀값은 보고서나 Git에 넣지 않는다. 향후 비공개 WRDS 자료를 받으면 접근·재배포 조건을 먼저 확인한다.

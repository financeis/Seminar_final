# 로컬 실행과 자료 보호

이 프로젝트에는 로그인, 계정 저장소, 공개 서버, 실거래 연결이 없다. 접근 권한은 실행하는 사용자의 운영체제 파일 권한을 따른다. 인증 토큰의 발급·만료·회전 기능도 현재 제공하지 않는다.

| 실행 주체 | 허용되는 동작과 조건 | 실패·제한 처리 |
|---|---|---|
| 진단 CLI | 지정 소스·CSV·NPZ·PDF 읽기, 지정 결과 폴더와 임시 폴더 쓰기 | 기준 해시가 다르면 검증 실패로 기록한다. 진단 중 원본을 고쳐 일치시키지 않는다. |
| 격리된 원 스크립트 | 준비한 임시 입력 소비와 그 폴더의 파생 파일 생성 | 네트워크 소켓 연결·이름 조회를 차단한다. 예외와 stdout/stderr를 보존한다. |
| 산출물 점검기 | 로컬 결과, 지정 PDF, 설치 버전, Git 기준 내용 읽기 | 입력 부재·참조 손상·해시 불일치를 성공으로 처리하지 않는다. |

보호 대상은 원 연구 코드와 입력의 무결성, 실자료/합성자료의 출처 구분이다. 실행 명령, 시각, 패키지 버전, seed, 읽은 소스 해시, 원본 전후 해시와 예외를 기록한다. 이 격리는 부작용을 제한하기 위한 장치이며 임의의 악성 Python 코드를 안전하게 실행하는 보안 샌드박스는 아니다.

현재 진단에는 자격 증명이 필요하지 않다. 사용자별 도구 설정이나 비밀값을 보고서·Git 산출물에 복사하지 않는다. 향후 비공개 WRDS 자료를 사용한다면 접근·보관·재배포 조건을 확인한 뒤 파일 계보에 출처와 이용 범위를 남겨야 한다. 공개 Yahoo 가격을 동일한 WRDS 원자료로 표시하지 않는다.

## 기준과 읽은 범위

기준은 사용자가 제공한 `idea_paper.pdf` 26쪽이다. SHA-256은 `1dfd2574208a52effd3fa195e6005e33122b54f19220b4fb974cae603fc1aaab`이다. 전체 텍스트와 관련 수식 페이지를 확인했다. 아래 페이지는 PDF의 1부터 시작하는 페이지 번호다. 저장소 PDF 및 2026년 출판본은 원문을 대체하지 않는다.

논문의 핵심은 **거시경제 관측 → 두 단계 군집 → 현재 레짐 확률 → 전이행렬을 통한 다음 레짐 확률 → 조건부 자산 예측 → 비중 → 평가**다. 좋은 성과가 나왔다고 해서 이 연결이 올바르게 구현된 것은 아니다.

Section 6은 **48개월 고정 창을 이동하면서 1개월 앞을 예측**한다고 명시한다. 예측을 만들 때 사용할 수 있는 자료의 상한, 실제 데이터 공개 지연, 수익률 구간 끝은 별도로 확인해야 한다. 본문이 모든 정보 시점 정책을 충분히 정하지는 않는다.

## 전처리와 군집

### DATA — FRED-MD (4.1~4.2, p.7)

원문은 127개 변수, 그룹 6(금리·환율) 제외, 1959-12~2023-01을 기술한다. t-code 변환 후 표준화하고 PCA의 누적 설명력 95%까지 선택한다. 본문이 보고한 61개 성분은 **그 자료에서 얻은 값**이다. 중심화한 48행의 행렬은 rank≤47이므로 모든 rolling 창에서 61개 성분을 요구하면 안 된다.

저장소 변환 부록 p.1의 t-code는 다음과 같다. Δ는 바로 전 관측과의 차이이고, 월 자료에서는 관측이 실제 연속 월인지 확인해야 한다.

| t-code | 변환 |
|---|---|
| 1 | x_t |
| 2 | x_t − x_(t−1) |
| 3 | x_t − 2x_(t−1) + x_(t−2) |
| 4 | log(x_t) |
| 5 | log(x_t) − log(x_(t−1)) |
| 6 | log(x_t) − 2log(x_(t−1)) + log(x_(t−2)) |
| 7 | (x_t/x_(t−1)−1) − (x_(t−1)/x_(t−2)−1) |

원문은 결측치 보간·행 삭제·변수 삭제의 세부 정책을 정하지 않는다. 전체 기간에서 변수를 고르는 정책과 매 창에서 사용할 수 있는 변수를 고르는 정책은 서로 다른 정보 집합을 사용한다.

### ALG1 — Algorithm 1 (3.1, pp.4~5)

1. L2 k-means, k=2로 A와 B를 나눈다.
2. 작은 군집을 R0로 둔다. 같은 크기이면 의사코드는 A를 R0로 둔다.
3. 나머지 관측에 cosine k-means를 적용하고 elbow로 r을 정한다.
4. R0와 R1~Rr를 반환한다. 실험 본문은 r=5를 사용한다.

본문은 알고리즘이 확률 분포를 반환한다고 설명하지만 의사코드의 반환값은 군집 집합이다. 실제 확률 변환은 다음 절이다. cosine k-means의 정확한 최적화·초기화·동률 처리와 창 사이 매칭 방식은 충분히 명세되지 않았다. 일반 k-means를 정규화된 자료에 적용하는 것과 구면 중심을 매번 정규화하는 spherical k-means는 별도 구현 선택이다.

| ID | 원문 | 수학적 의미·검증 기준 |
|---|---|---|

| EQ02 | 식 (2), p.6 | 일반 레짐 확률들의 Pmax=max_i P_i. 아직 R0와 결합하기 전 확률이다. |

| EQ04 | 식 (4), p.6 | q0=−Pmax log2(1−p0). [q0,P1,…,Pr]를 합으로 나누면 최종 분포다. p0=1은 극한으로 R0=1, 나머지=0. |
| EQ05 | 식 (5), p.6 | e_ij=N(i→j)/N(i). 마지막 관측의 출발 전이가 없으므로 문자 그대로 계산하면 마지막 레짐의 행 합이 1보다 작다. 아래 AMB01 참조. |
| EQ06 | 식 (6), p.13 | p를 다시 정규화한다. 본문이 합=1을 요구하므로 비음수 벡터의 원소 합을 분모로 읽는다. Euclidean norm으로 나누면 합=1을 보장하지 않는다. |

| EQ08 | 식 (8), p.14 | 다음 레짐 확률의 argmax를 선택한다. 표기 범위가 1~r+1로 앞의 R0~Rr와 어긋난다. |
| EQ09 | 식 (9), p.14 | Naive 예측값은 가장 가능성 높은 다음 레짐에 조건부인 Sharpe 추정치다. 수익률 예측 자체와 구별한다. |
| EQ10 | 식 (10), p.14 | 해당 레짐의 역사적 평균 수익률을 표준편차로 나눈다. 0분산·표본 부족 정책은 제시되지 않았다. |
| EQ11 | 식 (11), p.14 | BL의 view q는 가장 가능성 높은 다음 레짐의 역사적 평균 수익률이다. prior는 표본 평균·공분산이다. |
| EQ12 | 식 (12), p.14 | 레짐 i의 Ridge로 ETF j의 다음 수익률을 예측한다. 적힌 beta·X_(1:t)는 단일 예측의 차원과 맞지 않고, 조건부 레짐의 시간 첨자가 없다. |
| EQ13 | 식 (13), p.14 | ||y−X beta||²+lambda||beta||² 최소화. y도 X와 같은 학습 행이어야 한다. 절편·lambda 선택·X→y lag는 본문만으로 모두 결정되지 않는다. |

| EQ16 | 식 (16), p.15 | lns: H∪L에 대해 w_j=yhat_j/S_l, 나머지 0. 비어 있지 않으면 총 절대 노출은 1이다. |
| EQ17 | 식 (17), p.15 | los: 부호와 관계없이 절댓값 상위 l개 B에 대해 w_j=yhat_j/Σ_B|yhat|. |
| EQ18 | 식 (18), p.15 | lo: 양수 상위 최대 l개 H에 대해 w_j=yhat_j/Σ_H yhat. 모두 비양수이면 분모=0이며 현금 보유 같은 정책을 따로 정해야 한다. |
| EQ19 | 식 (19), pp.15~16 | [ (tau Sigma)^−1 + PᵀOmega^−1P ]^−1 [ (tau Sigma)^−1 mu + PᵀOmega^−1q ]. 형태는 BL posterior expected return이며 본문은 allocation이라 부른다. 비중 변환·risk aversion 등은 명확하지 않다. |

식 (1)의 성질: 동일한 거리에서는 균등 확률이다. K=5이면 한 중심과 거리가 0이어도 그 중심 확률의 상한은 1/(5−1)=0.25다. 이는 원문 휴리스틱 자체의 특징이며, 일반적인 역거리 가중이나 fuzzy c-means와 수치적으로 같다고 할 수 없다. 모든 거리=0 또는 K=1에서 원식은 정의되지 않는다.

식 (3)~(4)의 성질: q0>Pmax ⇔ p0>0.5이므로 2단계의 hard/soft 최빈 레짐을 일치시키려는 설계다. 클리핑은 구현상의 수치 안정화이며 p0=1에서 유한 근사 오차가 생긴다.

식 (14)의 R0 제외: p1+…+pr=1−p0이다. 양수/음수 순서가 유지되는 양의 공통 배율은 lo 비중 정규화에서 상쇄될 수 있으므로, 예측 크기 감소를 곧바로 비중 오류라고 해석하지 않는다. 위기 예측기 부재의 의미와 mx 전략의 존재는 별도 논점이다.

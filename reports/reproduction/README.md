# 재구현 결과

[한국어 보고서와 그림](report/report.md)에서 방법 설명·전략 성과·코로나 시기 제외 진단을 읽을 수 있습니다. [완료 기록](verification.json)에 명령·종료코드·실행 범위가 있습니다.

구 코드 제거와 테스트 예제 이관, 보고서 참조 갱신은 [최신 프로젝트 정리](project-cleanup.md)에 기록했습니다.

최종 통합 테스트는 **369개 통과**했습니다. 보고서 생성, 보고서 파일·출처 확인, 저장된 대표 비용 실험의 CLI 검증도 통과했습니다. 이미 확인한 전체 기간 산술 검사를 다시 반복하지 않았습니다.

| 자료 | 실제 확인 범위 |
|---|---|
| 기본 전략 | `1541930`에서 두 자료 방식 각각 2003-02~2022-12, 239개월 × 50개 전략 |
| 대조·민감도 | `ac069ce`에서 38개 독립 월 검사와 8개 연속 3개월 실행·재실행 |
| 전체 표본 해석 | 저장한 PCA·GMM·NBER·전이 그림과 코로나 제외 진단 재사용 |

100개 대조군과 모든 민감도의 전체 기간 실행, 최종 코드의 전체 실험 반복은 사용자 요청에 따라 생략했습니다. 논문 전체 실험의 완전 재현 인증은 아닙니다.

## 파일과 재사용

- report 아래의 PNG/SVG/CSV/JSON은 저장 결과를 읽어 생성한 사본입니다.
- evidence-bundle.json은 보고서에 사용한 기존 실행과 참조를 지정합니다.
- 큰 원자료와 창별 모형은 Git에 넣지 않았습니다. 현재 컴퓨터의 data/raw와 저장소 부모 work/rebuild-execution에 보존돼 있습니다.
- 원본까지 재검증하려면 해당 자료와 참조 경로가 필요합니다. 보고서 파일만 다른 컴퓨터에 복사하면 표·그림은 읽을 수 있지만, 원본 출처 검사까지 재현되지는 않습니다.
- verification.json의 revision은 최종 계산 코드·CLI를 검사한 버전입니다. 이후 문서·결과물 저장 커밋은 별개입니다.
